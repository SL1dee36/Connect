# Connect Android

Нативный Android-клиент для мессенджера Connect, построенный на современном стеке Jetpack Compose в соответствии с рекомендациями Material 3.

## Стек технологий и требования

- **Android SDK**: `minSdk 26` (Android 8.0+), `targetSdk 35`, `compileSdk 35`
- **Язык и среда**: Kotlin 2.0.21, Java 17 (JVM target 17), Gradle 8.7+
- **UI фреймворк**: Jetpack Compose, Material 3 (Material Design Expressive)
- **Сетевой слой**: Retrofit 2, OkHttp 4, Socket.IO Client 2.1
- **Медиа и камера**: CameraX 1.4 (запись видео-заметок), Media3 ExoPlayer 1.4 (воспроизведение аудио и видео), Coil 2.7
- **Безопасность**: AndroidX Biometric (вход по отпечатку пальца и Face Unlock)
- **Многопоточность**: Kotlin Coroutines, Flow

## Основные возможности

- **Сообщения и чаты**: личные и групповые диалоги в реальном времени через WebSockets (Socket.IO).
- **Медиа и файлы**: отправка документов и медиафайлов через нативный системный выбор файлов, запись и воспроизведение голосовых сообщений и круглых видео-заметок.
- **Персонализация**: поддержка динамических цветов системы (Material You / Monet), светлой, тёмной и AMOLED тем, выбор акцентных цветов, регулировка скругления блоков сообщений и размера шрифта.
- **Профиль и безопасность**: биометрическая аутентификация, редактирование данных аккаунта, история аватаров, управление активными сессиями.
- **Интеграция с платформой**: поддержка нативных отступов безопасных зон (Edge-to-Edge, Safe Area Insets) и системного жеста «Назад» (BackHandler).

## Сборка и запуск

Для сборки необходим установленный JDK 17 и Android SDK.

- **Сборка отладочной версии (Debug APK)**:
  ```bash
  ./gradlew assembleDebug
  ```
  Итоговый файл: `app/build/outputs/apk/debug/app-debug.apk`

- **Сборка релизной версии (Release APK)**:
  ```bash
  ./gradlew assembleRelease
  ```
  Итоговый файл: `app/build/outputs/apk/release/app-release.apk`

- **Установка на устройство или эмулятор**:
  ```bash
  adb install -r app/build/outputs/apk/debug/app-debug.apk
  ```
